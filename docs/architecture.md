# 仿真器实现说明

本文说明 `src/sim/Simulator.cpp` 中的数学模型与装配细节，便于后续扩展元件与算法。

## 1. 网表与未知量

`Netlist::build()` 将原理图几何转换为节点编号：

1. 每个引脚、每个导线顶点按 10 px 网格取整为 `QPoint` 键；
2. 每条导线段的两个端点做并查集合并；
3. 引脚或**导线顶点**若落在某条导线段内部（严格位于两端点之间），与该段端点合并（T 型连接）；
4. 所有接地符号所在集合编号为 0，其余集合按首次出现顺序编号 1…N。

求解未知量排列为：

```
x = [ v1, v2, ..., vN, i1, i2, ..., iM ]ᵀ
```

- `v_k`：节点 k 的电压（相对地）
- `i_j`：第 j 条支路电流（电压源与电感），方向定义为元件引脚 0 → 引脚 1

线性系统为 `A x = b`，其中节点行是 KCL，支路行是元件约束。

## 2. 元件占位（stamp）

记节点 n1 的未知量下标为 `n1-1`（地节点 0 不产生未知量）。

### 电阻

```
G = 1/R
A[n1,n1] += G    A[n2,n2] += G
A[n1,n2] -= G    A[n2,n1] -= G
```

### 电容（瞬态，后向欧拉）

```
i = C/h · (v(t) - v(t-h)) = G·v(t) - G·v(t-h),  G = C/h
```

KCL 中把常量移到右端，等价于在 n1→n2 之间接入一个电流源 `-G·v(t-h)`：

```
A 上 stamp G；b[n1] += G·v(t-h)，b[n2] -= G·v(t-h)
```

直流工作点分析时电容开路（不 stamp）。

### 电感（瞬态，后向欧拉）

以支路电流 `i` 为未知量：

```
v1 - v2 = L/h · (i - i(t-h))
=> v1 - v2 - (L/h)·i = -(L/h)·i(t-h)
```

支路行写入 `+1, -1, -L/h`，右端为 `-(L/h)·i(t-h)`。直流时 `L/h = 0`，电感即 0 V 电压源（短路）。

### 独立电压源

```
v1 - v2 = V(t)
支路行：+1, -1, 0
KCL 列：A[n1,ib] += 1，A[n2,ib] -= 1
```

### 独立电流源

电流自 n1 经电源流向 n2：

```
b[n1] -= I(t)，b[n2] += I(t)
```

### 二极管

```
I(v) = Is·(e^(v/(n·Vt)) - 1)
g(v) = Is·e^(v/(n·Vt)) / (n·Vt)
```

牛顿线性化：`i ≈ g(v0)·v + (I(v0) - g(v0)·v0)`，第一项 stamp 为电导，第二项作为电流源。
每次迭代后用 pnjlim 限制电压跳变：

```
若 v_new > v_crit 且 |v_new - v_old| > 2·Vt：
    v_old > 0 时  v_new = v_old + Vt·ln(1 + (v_new - v_old)/Vt)
    否则          v_new = Vt·ln(v_new/Vt)
最后限制在 [-5, 1] V 内
```

### 发光二极管（LED）

和普通二极管共用同一个方程，只是参数不同：

```
Is = 20 mA / (e^(Vf / (n·Vt)) − 1)      n = 2
```

也就是「20 mA 时正向压降正好等于 Vf」。`Vf` 默认 2 V（红色 LED），
可以按器件改成 1.8~3.3 V。

注意两点：

- 结电压限幅 `pnjlim` 的上限必须放宽。硅二极管卡在 0.9 V 没问题，
  LED 的 2 V 压降会被卡死，迭代永远收敛不到工作点。
- 指数项的电压上限同理，LED 模型单独设成 `max(4 V, Vf + 1.5 V)`。

反向击穿、发光强度与温漂都没有建模。

### 三极管（NPN / PNP，Ebers-Moll）

引脚顺序：`0 = 集电极 C`、`1 = 基极 B`、`2 = 发射极 E`。

```
If = Is·(e^(Vbe/Vt) − 1)      Ir = Is·(e^(Vbc/Vt) − 1)
Ic = αF·If − Ir               Ib = (1−αF)·If + (1−αR)·Ir
αF = β/(1+β)                  αR = 0.5
```

牛顿迭代时把 `Ic`、`Ib` 对 `Vbe`、`Vbc` 线性化：跨导项写成两个 VCCS
（受 `Vb−Ve` 与 `Vb−Vc` 控制），常数项作为等效电流源。两个结电压都用
`pnjlim` 限幅，避免指数项把迭代踢飞。

PNP 与 NPN 是镜像关系：结电压取反后方程完全相同，只需把端电流乘回 −1。
实现上用一个 `sign` 因子，存储的状态始终是“归一化后的正向结电压”。

### MOS 管（N / P 沟道，level-1 平方律）

引脚顺序：`0 = 漏极 D`、`1 = 栅极 G`、`2 = 源极 S`（栅极电流为 0）。

```
Vov = Vgs − Vth
截止  (Vov ≤ 0):  Id = 0
线性  (Vds < Vov): Id = K·(Vov·Vds − Vds²/2)
饱和  (Vds ≥ Vov): Id = K/2·Vov²
```

`gm = ∂Id/∂Vgs`、`gds = ∂Id/∂Vds`，另加 1 nS 的下限避免矩阵奇异。
每次迭代把 `Vgs`、`Vds` 的变化限制在 0.5 V 以内，防止平方律模型来回跳。
PMOS 同样用 `sign = −1` 归一化：`Vgs' = Vs − Vg`、`Vds' = Vs − Vd`。

### IGBT

没有通用 SPICE 模型，这里用「栅极像 MOSFET、输出侧带导通压降」的简化模型：

```
Id = MOSFET 平方律(Vge, Vce − Vf)
```

即把输出侧压降 Vf（默认 0.7 V）折进漏源电压里。饱和压降、拖尾电流等
开关特性没有建模，只适合验证通断与大致工作点。

### TL431（可调基准）

引脚：`0 = REF`、`1 = 阳极 A`、`2 = 阴极 K`。

```
Vref > Vref0 时：Ik = G·(Vref − Vref0)，G = 100 S
阴极-阳极之间另有一只正向二极管，避免 Vka 被拉到负值
```

- 分流管用「线性跨导 + 截止」描述，不用指数：REF 与阴极短接时指数增益过高，
  牛顿迭代会发散
- 线性化的展开点必须是**当前工作点**而不是阈值，否则每次迭代都多算一截电流
- 迭代里对 Vref 做 0.1 V/步的限幅，并把变化量计入收敛判据

### 光耦（Optocoupler）

引脚：`0 = 输入 LED 阳极`、`1 = 阴极`、`2 = 输出集电极`、`3 = 发射极`。

```
If  = LED 方程(Vf)                    // 与发光二极管同一套模型
x   = Vce / Vce(sat)                  // 输出侧归一化压降
Ic  = CTR · If · x/(1+x)              // 单调平滑，Vce→0 时截止，Vce≫Vce(sat) 时接近 CTR·If
```

饱和特性不能省：只用恒流源时，高 CTR 会把发射极顶到集电极之上（例如 5 V 供电
算出 10 V）。`x/(1+x)` 在 0 处有右侧导数，牛顿迭代不会在「全电流 / 零电流」
之间来回跳；分段折线则会在边界振荡。

输出侧再并 1 nS 漏电导，避免光敏三极管悬空时矩阵奇异。
默认参数取自 LTV-817S-TA1-C（Lite-On）：

| 参数 | 值 | 数据手册 |
| --- | --- | --- |
| Vf | 1.2 V | typ @ If = 20 mA（max 1.4 V） |
| CTR | 3.0 | C 档 200–400% @ If = 5 mA、Vce = 5 V |
| Ic 上限 | 50 mA | 未在模型中限制 |
| Vce(sat) | 0.1/0.2 V | 未建模，输出侧按理想电流源 |
| 截止频率 | 80 kHz | 未建模（无传输延迟） |

CTR 与 Vf 都能在属性面板里改。反向击穿、温漂、饱和压降与传输延迟没有建模。

### 运算放大器（三端理想 VCVS）

引脚顺序：`0 = 同相输入`、`1 = 反相输入`、`2 = 输出`。输出端增加一个支路电流未知量，
支路连接在 (out, 0) 之间：

```
v_out - R_out·i_out = A·(v_in+ - v_in-)
```

装配时先按支路 stamp `v_out - 50·i_out = 0`，再在支路行写入 `-A`（同相）与 `+A`（反相）：

```
A[ib, in+] -= A
A[ib, in-] += A
```

`R_out = 50 Ω` 让输出不会与电容或理想电压源形成奇异回路；`A` 取自元件数值（默认 1e5）。
饱和、带宽与压摆率未建模，因此输出可能超出真实电源轨。

### 开关

闭合用 1 mΩ、断开用 1 GΩ 的电导近似，避免理想开关造成矩阵奇异。

### gmin

每个非地节点对地加 `1e-12 S`，用于稳定纯浮空节点；对常规电路结果影响可忽略。

### 测试点

测试点不改变电路功能，只在结果中挑选信号：

- **电压测试点 TP**：单引脚，和接地符号一样只参与网表连通性，映射到某个节点后取 `V(node)`。
- **电流测试点 IP**：二引脚，等效为 0 V 电压源串入支路，支路电流未知量就是被测电流；会新增一个节点与一条支路，因此网表节点数会变化。

仿真结果先生成全部节点电压与元件电流，再按测试点过滤并重命名（`TP1 (V(2))`、`IP1 (I)`）。
没有测试点时波形列表为空。

## 3. 牛顿迭代与收敛

每次迭代重新装配 `A`、`b` 并求解，收敛判据（同时满足）：

```
max|Δv| ≤ 1e-6·(1 + max|v|) + 1e-9
max|Δv_diode| ≤ 1e-7
```

最多 150 次迭代。若矩阵主元低于 `1e-13`，报“线性方程组奇异”，常见原因是电压源短路回路、
理想电压源并联或悬空节点。

## 4. 瞬态分析流程

1. 用 `t = 0` 的源值求直流工作点；
2. 由工作点初始化所有电容电压 `v_C` 与电感电流 `i_L`；
3. 以固定步长 `h` 推进：每个时间点做一次牛顿求解，随后用新解更新 `v_C`、`i_L`；
4. 记录所有节点电压与元件电流。

步数上限 200000；超过时自动增大步长并写入日志。

## 5. 交流小信号分析

1. 先求直流工作点，得到二极管的小信号电导；
2. 对每个频点 `ω = 2πf` 装配复数矩阵：

```
电阻：G          电容：jωC
电感：支路阻抗 jωL
电压源：支路右端 1∠0（单位激励）
电流源：右端 1∠0
二极管：g(v_op)
```

3. 求解后输出各节点 `20·log10|V|`（dB）。频率按对数等间隔取点。

## 7. 扩展指引

- **新增线性元件**：在 `ComponentType` 增加类型，在 `assembleReal` / `assembleAc` 添加 stamp，
  并在 `paintSymbol` 与 `PropertyPanel` 中补充显示与参数。
- **新增非线性元件**：仿照二极管，在 `ElementState` 保存迭代变量，装配时线性化，
  并在牛顿循环中更新状态与限幅。
- **更高精度瞬态**：把 `assembleReal` 中的 `C/h`、`L/h` 换成梯形法系数，
  同时保存上一时刻的电流/电压，即可获得二阶精度。
