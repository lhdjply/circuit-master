# 仿真器实现说明

本文说明 `src/sim/Simulator.cpp` 中的数学模型与装配细节，便于后续扩展元件与算法。

## 1. 网表与未知量

`Netlist::build()` 将原理图几何转换为节点编号：

1. 每个引脚、每个导线顶点按 10 px 网格取整为 `QPoint` 键；
2. 每条导线段的两个端点做并查集合并；
3. 引脚或**导线顶点**若落在某条导线段内部（严格位于两端点之间），与该段端点合并（T 型连接）；
4. 所有接地符号所在集合编号为 0，其余集合按首次出现顺序编号 1…N。

求解未知量排列为：

```
x = [ v1, v2, ..., vN, i1, i2, ..., iM ]ᵀ
```

- `v_k`：节点 k 的电压（相对地）
- `i_j`：第 j 条支路电流（电压源与电感），方向定义为元件引脚 0 → 引脚 1

线性系统为 `A x = b`，其中节点行是 KCL，支路行是元件约束。

## 2. 元件占位（stamp）

记节点 n1 的未知量下标为 `n1-1`（地节点 0 不产生未知量）。

### 电阻

```
G = 1/R
A[n1,n1] += G    A[n2,n2] += G
A[n1,n2] -= G    A[n2,n1] -= G
```

### 电容（瞬态，后向欧拉）

```
i = C/h · (v(t) - v(t-h)) = G·v(t) - G·v(t-h),  G = C/h
```

KCL 中把常量移到右端，等价于在 n1→n2 之间接入一个电流源 `-G·v(t-h)`：

```
A 上 stamp G；b[n1] += G·v(t-h)，b[n2] -= G·v(t-h)
```

直流工作点分析时电容开路（不 stamp）。

### 电感（瞬态，后向欧拉）

以支路电流 `i` 为未知量：

```
v1 - v2 = L/h · (i - i(t-h))
=> v1 - v2 - (L/h)·i = -(L/h)·i(t-h)
```

支路行写入 `+1, -1, -L/h`，右端为 `-(L/h)·i(t-h)`。直流时 `L/h = 0`，电感即 0 V 电压源（短路）。

### 独立电压源

```
v1 - v2 = V(t)
支路行：+1, -1, 0
KCL 列：A[n1,ib] += 1，A[n2,ib] -= 1
```

### 独立电流源

电流自 n1 经电源流向 n2：

```
b[n1] -= I(t)，b[n2] += I(t)
```

### 二极管

```
I(v) = Is·(e^(v/(n·Vt)) - 1)
g(v) = Is·e^(v/(n·Vt)) / (n·Vt)
```

牛顿线性化：`i ≈ g(v0)·v + (I(v0) - g(v0)·v0)`，第一项 stamp 为电导，第二项作为电流源。
每次迭代后用 pnjlim 限制电压跳变：

```
若 v_new > v_crit 且 |v_new - v_old| > 2·Vt：
    v_old > 0 时  v_new = v_old + Vt·ln(1 + (v_new - v_old)/Vt)
    否则          v_new = Vt·ln(v_new/Vt)
最后限制在 [-5, 1] V 内
```

### 运算放大器（三端理想 VCVS）

引脚顺序：`0 = 同相输入`、`1 = 反相输入`、`2 = 输出`。输出端增加一个支路电流未知量，
支路连接在 (out, 0) 之间：

```
v_out - R_out·i_out = A·(v_in+ - v_in-)
```

装配时先按支路 stamp `v_out - 50·i_out = 0`，再在支路行写入 `-A`（同相）与 `+A`（反相）：

```
A[ib, in+] -= A
A[ib, in-] += A
```

`R_out = 50 Ω` 让输出不会与电容或理想电压源形成奇异回路；`A` 取自元件数值（默认 1e5）。
饱和、带宽与压摆率未建模，因此输出可能超出真实电源轨。

### 开关

闭合用 1 mΩ、断开用 1 GΩ 的电导近似，避免理想开关造成矩阵奇异。

### gmin

每个非地节点对地加 `1e-12 S`，用于稳定纯浮空节点；对常规电路结果影响可忽略。

### 测试点

测试点不改变电路功能，只在结果中挑选信号：

- **电压测试点 TP**：单引脚，和接地符号一样只参与网表连通性，映射到某个节点后取 `V(node)`。
- **电流测试点 IP**：二引脚，等效为 0 V 电压源串入支路，支路电流未知量就是被测电流；会新增一个节点与一条支路，因此网表节点数会变化。

仿真结果先生成全部节点电压与元件电流，再按测试点过滤并重命名（`TP1 (V(2))`、`IP1 (I)`）。
没有测试点时波形列表为空。

## 3. 牛顿迭代与收敛

每次迭代重新装配 `A`、`b` 并求解，收敛判据（同时满足）：

```
max|Δv| ≤ 1e-6·(1 + max|v|) + 1e-9
max|Δv_diode| ≤ 1e-7
```

最多 150 次迭代。若矩阵主元低于 `1e-13`，报“线性方程组奇异”，常见原因是电压源短路回路、
理想电压源并联或悬空节点。

## 4. 瞬态分析流程

1. 用 `t = 0` 的源值求直流工作点；
2. 由工作点初始化所有电容电压 `v_C` 与电感电流 `i_L`；
3. 以固定步长 `h` 推进：每个时间点做一次牛顿求解，随后用新解更新 `v_C`、`i_L`；
4. 记录所有节点电压与元件电流。

步数上限 200000；超过时自动增大步长并写入日志。

## 5. 交流小信号分析

1. 先求直流工作点，得到二极管的小信号电导；
2. 对每个频点 `ω = 2πf` 装配复数矩阵：

```
电阻：G          电容：jωC
电感：支路阻抗 jωL
电压源：支路右端 1∠0（单位激励）
电流源：右端 1∠0
二极管：g(v_op)
```

3. 求解后输出各节点 `20·log10|V|`（dB）。频率按对数等间隔取点。

## 6. 数值验证

`tests/test_core.cpp` 中的基准：

| 用例 | 期望 | 实测 |

| 运放反相放大（R2/R1 = 10） | -10.00 V | -10.00 V |
| 运放交流增益（同电路） | 20 dB | 20.0 dB |
| 电流测试点（反馈支路 1 mA） | 1.000 mA | 1.000 mA |

## 7. 扩展指引

- **新增线性元件**：在 `ComponentType` 增加类型，在 `assembleReal` / `assembleAc` 添加 stamp，
  并在 `paintSymbol` 与 `PropertyPanel` 中补充显示与参数。
- **新增非线性元件**：仿照二极管，在 `ElementState` 保存迭代变量，装配时线性化，
  并在牛顿循环中更新状态与限幅。
- **更高精度瞬态**：把 `assembleReal` 中的 `C/h`、`L/h` 换成梯形法系数，
  同时保存上一时刻的电流/电压，即可获得二阶精度。
